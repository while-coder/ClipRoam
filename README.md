# ClipRoam

ClipRoam 用来保存剪贴板历史，并在自己的多台设备之间同步文字、图片、文件和文件夹。

- **Server（服务端）**：部署在一台设备都能访问的电脑或服务器上，负责账号、历史记录和文件同步。
- **App（客户端）**：安装在日常使用的电脑或手机上，用来记录、查找和使用剪贴板内容。

一般只需要部署一个 Server，然后让各台设备上的 App 连接同一个 Server、登录同一个账号。

## Server：部署与管理

### 启动服务

1. 在服务器上安装 Docker。
2. 从 [发布页面](https://github.com/while-coder/ClipRoam/releases) 下载 `cliproam-server.tar`。
3. 在下载目录运行以下命令，导入镜像：

   ```bash
   docker load -i cliproam-server.tar
   ```

4. 启动服务。将下面的 `版本号` 替换为下载版本（例如 `0.2.0`），并填写自己的管理员密码：

   ```bash
   docker run -d --name cliproam-server --restart unless-stopped -p 4810:4810 -e CLIPROAM_ADMIN_PASSWORD="请替换为自己的管理员密码" -v cliproam-data:/root/.cliproam cliproam-server:版本号
   ```

启动后，App 使用的服务器地址为 `服务器 IP 或域名:4810`，例如 `192.168.1.20:4810`。请确保使用 App 的设备能够访问这个地址；在另一台设备上连接时，不要填写 `127.0.0.1`。

需要使用其他端口时，可将命令中的 `-p 4810:4810` 改成 `-p 8080:4810`，App 中相应填写 `服务器地址:8080`。

### 使用管理后台

在浏览器打开 `http://服务器地址:4810/admin`，使用启动时设置的管理员密码登录。管理员密码与 App 的用户账号密码分别使用。

后台可以：

- 查看服务状态和用户数量。
- 管理用户、重置用户密码或删除账号。
- 查看和删除服务器保存的文件。
- 调整历史条数、单次复制文件数和文件大小等限制。
- 配置 HTTPS 证书。

通过公网使用时，请先配置 HTTPS。在后台上传证书和私钥后，按页面提示重启服务，再使用 `https://服务器地址:4810/admin` 访问后台，App 中也改选 HTTPS。首次配置证书请在受信任的网络中操作。

删除账号会清除该账号的历史；删除服务器文件会影响相关历史内容的再次使用，请在操作前确认。

### 停止、重启与备份

```bash
docker stop cliproam-server
docker start cliproam-server
docker restart cliproam-server
```

账号、历史和文件保存在上面创建的 `cliproam-data` 数据卷中。备份时请先停止服务，再备份整个数据卷；恢复时也需要完整恢复。更新或重新部署时，继续使用这个数据卷即可保留数据。

## App：安装与使用

### 安装和登录

1. 从 [发布页面](https://github.com/while-coder/ClipRoam/releases) 下载适合自己系统的安装包并安装。
2. 打开 App，填写服务器地址，例如 `192.168.1.20:4810`。
3. 根据服务器配置选择 HTTP 或 HTTPS。
4. 首次使用选择“注册”，创建账号；已有账号则选择“登录”。
5. 在其他设备上填写相同的服务器地址，并登录同一个账号。

不同账号的历史和设备列表互相独立。服务器由别人管理时，向管理员获取服务器地址和连接协议即可。

### 桌面端：记录和使用剪贴板

保持 App 运行，并在设置中开启“监听剪贴板”。之后像平常一样复制文字、图片、文件或文件夹，内容会自动进入 ClipRoam 并同步。

- **查找历史**：在主界面的搜索框输入关键词，按 Enter 搜索，也可以按内容类型筛选。
- **复制历史内容**：点击条目，或选中条目后按 Enter，再到目标应用中粘贴。
- **快捷粘贴**：在目标应用中按 `Ctrl + Shift + V`（macOS 为 `Cmd + Shift + V`），选择历史内容即可粘贴。快捷键可以在设置中修改。
- **更多操作**：右键点击条目，可复制、预览图片或文件、另存为或删除。

macOS 首次使用自动粘贴时，需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 ClipRoam。若无法自动粘贴，可先复制条目，再手动粘贴。

### 跨设备同步

多台设备连接同一服务器并登录同一账号后，可以查看同一份剪贴板历史。

桌面端开启“自动接收剪贴板”后，其他设备复制的文字、富文本和图片会自动更新本机剪贴板，可直接在当前应用中粘贴。关闭后，仍可从历史中手动选择内容。

文件和文件夹会同步到历史，需要手动选择复制、粘贴或另存为。

### 文件传输

在“设置 → 文件同步”中，可以选择自动上传文件的大小上限，也可以关闭自动上传。

- 已上传到服务器的文件，其他设备使用时无需保持源设备在线。
- 未自动上传的文件，其他设备使用时需要源设备保持在线、App 保持运行，且原文件仍可读取。
- 复制文件后，可在“待上传”中查看处理进度；使用远端文件时，可在“下载”中查看传输进度。
- “下载”记录保存在当前账号的本地 SQLite，各账号独立，重启后仍可查看。每次下载汇总为一条记录，可展开文件详情；保留最近 30 天、最多 500 条已结束记录，也可手动删除或清空。清理记录不会删除已下载的文件。
- 不想同步某些文件时，可在“复制过滤”中填写要忽略的名称。

### 手机端

手机端可以查看、搜索和删除历史，但不会像桌面端一样持续在后台监听剪贴板。

- 在“剪贴板历史”界面点击“读取当前剪贴板”，导入当前复制的文字。
- 点按历史中的文字，将它复制到系统剪贴板，再到其他应用中粘贴。
- Android 可以通过系统分享菜单，将文字、图片或文件分享给 ClipRoam。
- Android 点按图片或文件后，选择保存目录即可下载；下载中再次点按同一条目可取消。
- iOS 的图片和文件目前下载到应用缓存，系统分享和文件导出暂未支持。

### 常见问题

**连接不上服务器**

确认 Server 正在运行，地址和端口填写正确，HTTP/HTTPS 与服务器一致，并且当前设备能访问服务器。必要时请管理员检查网络和端口设置。

**复制的内容没有进入历史**

桌面端确认 App 正在运行且已开启“监听剪贴板”，再检查“待上传”和连接状态。手机端请使用“读取当前剪贴板”，或在 Android 上通过分享菜单导入。复制的文件也可能被过滤规则或服务器限制排除。

**历史中的文件无法下载**

若文件没有上传到服务器，请保持源设备在线、App 运行，并确认原文件还在。若服务器上的文件已被删除，需要从源设备重新复制并同步。

# 随心贴 VS Code 扩展

在编辑器标签页中使用随心贴，共用登录、历史、设置与同步业务。需要连接已部署的随心贴 Server。

## 使用

安装 VSIX 后，点击窗口标题栏或编辑器标题栏中的随心贴图标，或在命令面板运行 `随心贴: 打开剪贴板历史`，填写服务器地址并登录。重复打开会回到已有的随心贴标签页。

- **添加选中文本**：选中编辑器文本，右键选择 `添加到随心贴历史`，也可从命令面板运行对应命令。文本加入当前账号的上传队列。
- **使用历史文本**：在随心贴历史中复制文本，再回到编辑器粘贴。主界面与其他客户端一致，不显示编辑器专属工具栏。
- **读取剪贴板**：使用历史界面的“读取当前剪贴板”操作。

首次安装或重新打开标签页时，需要等待登录验证完成再保存文本。登录和缓存沿用共享客户端的 Webview IndexedDB。关闭标签页后同步停止，重新打开会恢复保存的连接设置并验证会话。

首版支持桌面 VS Code，使用本地 UI 扩展宿主；没有浏览器版扩展入口。仅支持文本剪贴板，不监听系统复制，不提供全局快捷键；图片和文件可以查看、传输到应用缓存，系统图片/文件复制和原生文件导出暂不支持。

## 构建和调试

在仓库根目录执行：

```bash
pnpm install
pnpm build:vscode
pnpm package:vscode
```

VSIX 位于 `apps/vscode/dist/cliproam.vsix`。在 VS Code 扩展菜单中选择“从 VSIX 安装”。开发时选择仓库的 `Launch VS Code Extension` 调试配置，按 F5 启动扩展开发宿主。

构建后可运行 `pnpm --filter cliproam-vscode test`，验证扩展宿主消息桥、选中文本添加和标签页关闭清理。测试使用模拟 VS Code API；真实窗口的登录、同步和 Webview 行为需要在扩展开发宿主中验证。

扩展通过受限消息桥调用 VS Code 文本剪贴板、文本编辑器和外部链接 API。Webview 仅允许加载打包资源，HTTP/WebSocket 连接用于访问用户配置的服务器。
